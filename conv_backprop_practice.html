Cheat sheet (window k = the patch that produced yk, dk = dout entry):
• dW = Σk dk · windowk   (S2: ∂L/∂k(a,b) = Σr,c G(r,c)·x(s·r+a, s·c+b))
• dX[patch k] += dk · W, overlaps add   (S2: ∂L/∂x(r′,c′) = Σa,b G(r′−a,c′−b)·k(a,b), stride 1)
• db = Σ dout  ·  padding: compute dX on the padded input, then crop the padding  ·  output size ⌊(N−K+2P)/S⌋+1
• Every gradient has the shape of the thing it differentiates.

Cheat sheet: counting parameters and activations (Cin = input depth, bias = 1 per filter/node; set to 0 if the question says "no bias")
• conv: output side = ⌊(N−K+2P)/S⌋+1, depth = #filters  ·  params = (K·K·Cin + 1)·Cout (independent of the image size, stride and padding)
• pooling: depth unchanged, 0 parameters  ·  FC: flatten first, params = (Nin + 1)·Nout (depends on the input size!)
• activations of a layer = Hout·Wout·Cout (the numbers it outputs; they must be stored for backprop)  ·  memory = count × bytes (float32 = 4 B)
• Lecture takeaways (VGG-16): most memory is in the early conv layers (big activations); most parameters are in the FC layers (FC1 = 7·7·512·4096 = 102,760,448).
